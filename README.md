# Portfolio

池田 健作のポートフォリオサイトです。実際に使われたアプリを2つ、画面と一緒に紹介しています。

**公開URL**: https://ikcoding-jp.github.io/portfolio/

## 掲載している作品

| 作品 | 内容 | リンク |
|------|------|--------|
| RoastPlus | ドリップパックコーヒー製造現場向けの業務支援PWA。現場で約8か月使われた | [サイト](https://roastplus-72fa6.web.app) / [GitHub](https://github.com/IKcoding-jp/RoastPlus) |
| まいカゴ | 買い物中の合計金額を見える化する買い物リストアプリ。Google Play で公開中 | [Google Play](https://play.google.com/store/apps/details?id=com.ikcoding.maikago&hl=ja) / [GitHub](https://github.com/IKcoding-jp/Maikago) |

## 作り

- フレームワークを使わない素の HTML / CSS / JavaScript。ビルド不要
- 色・余白・書体は `tokens.css` にデザイントークン（見た目のルールを変数にまとめたもの）として定義し、`style.css` はその値だけを使う
- `script.js` は RoastPlus の画面スライダー（矢印・ドット・自動切り替え）
- GitHub Pages で公開
- 実装は Claude Code と一緒に行った

## 手元で見る

`index.html` をブラウザで開くだけで表示できます。
